## ✅ How to Get Started (each member, first day)

1. **Clone the repo:**
   ```bash
   git clone https://github.com/LETHABO113/Duplicate-File-Finder.git
   cd Duplicate-File-Finder
   ```

2. **Check it builds:**
   ```bash
   mvn clean package
   ```

3. **Check tests run:**
   ```bash
   mvn test
   ```

4. **Create your branch:**
   ```bash
   git checkout -b feature/<your-name>-<your-class>
   ```

5. **Create your Java class** in the correct package (see Project Structure below).

6. **Write at least one JUnit test** for your class.

7. **Push and open a Pull Request** into `develop`.
